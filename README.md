# Nehal // High-Tech Cyber Portfolio (1st Year B.Tech CS & AI) 🚀⚡

A futuristic, high-tech, and super-attractive interactive portfolio designed for **Nehal**, 1st Year Undergrad pursuing **B.Tech in Computer Science & Artificial Intelligence** at **Rishihood University (Newton School of Technology)**, hailing from **Kota, Rajasthan**.

---

## 🌌 Futuristic Features

### 1. 🎵 Built-In Web Audio API Synthesizer & Musical Effects
- **Zero External MP3s:** Uses pure client-side `AudioContext` mathematical sound synthesis. Instant, zero lag, works 100% offline.
- **Cyber Ambient Music:** Click the **`[MUSIC: OFF / ON]`** button in the top navbar to hear a calming, futuristic ambient synthesizer arpeggio (in Dorian minor chords) with active pulsing equalizer visualizer bars!
- **Interactive Sound FX:** Sci-fi audio blips on button hovers, snappy clicks on selection, and melodic chimes on theme switches.

### 2. 🎨 Varied Color Spectrum (4 Live Color Palettes)
Switch color themes seamlessly via the top-right color pills or via the terminal CLI:
- 🟣 **Cyberpunk Neon:** Electric Cyan (`#00f2fe`), Hot Magenta (`#ff007f`), and Deep Violet.
- 🔵 **Quantum Azure:** High-tech Sky Blue (`#38bdf8`), Azure Indigo, and Seafoam Green.
- 🟢 **Matrix Emerald:** Toxic Emerald (`#00ff87`), Neon Mint, and Dark Carbon.
- 🟡 **Solar Flare:** Amber Gold (`#ffb703`), Crimson Sunset, and Warm Tangerine.

### 3. 🧠 The Curiosity Reactor (Mindset & Hunger for Learning)
- Dedicated section highlighting your superpower: **"An insatiable hunger for learning new things & very curious"**.
- Highlights deep neural explorations, first-principles thinking grounded in Kota's academic rigor, and rapid software prototyping.

### 4. ♟️ The Trinity of Passions (Hobbies)
- 💻 **Coding:** Software architecture, clean logic, AI scripting, and web development.
- ♟️ **Competitive Chess:** Calculation of variation trees, pattern recognition, and endgame composure under clock pressure.
- 🏊‍♂️ **Swimming:** High lung endurance, disciplined rhythm, physical grit, and mental reset.

### 5. 💻 Live Interactive Cyber Command Terminal (CLI)
- Located in Section 04. Visitors can click preset pills or type commands directly:
  - `about` : Full profile dossier
  - `curiosity` : Deep dive into your learning hunger
  - `hobbies` : Coding, chess, and swimming details
  - `skills` : Tech stack and AI foundations
  - `music` : Toggles the background ambient synthesizer
  - `theme [matrix|cyberpunk|quantum|solar]` : Changes the website color palette via command line!
  - `clear` : Wipes terminal screen

### 6. 🌐 Interactive Neural Constellation Background
- An HTML5 canvas simulating connecting neural synapses.
- Nodes gravitate toward your mouse cursor and draw glowing multi-color lasers.
- Clicking anywhere generates an expanding cyber shockwave ripple!

## 🖥️ How to Preview

Run a lightweight local server:
```bash
python3 -m http.server 8000
```
Then open your browser at: **[http://localhost:8000](http://localhost:8000)** or simply double-click `index.html`.
